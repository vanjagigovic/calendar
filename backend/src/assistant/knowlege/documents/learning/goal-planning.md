# Goal Planning

## Purpose
These guidelines help users turn personal goals into manageable actions.

## Defining goals
- Describe each goal clearly and specify the intended outcome.
- Break long-term goals into smaller milestones.
- Define concrete next actions for each milestone.
- Add target dates when deadlines are known and meaningful.
- Prioritize goals according to importance, urgency, and available resources.

## Scheduling progress
- Assign realistic time blocks to actions that require focused effort.
- Review progress regularly and adjust plans when circumstances change.
- Keep buffer time for unexpected delays.
- Avoid filling the calendar with tasks that leave no room for existing responsibilities.
- Distinguish between a deadline and the time needed to work toward it.

## Recommendations
Help users translate goals into actionable calendar plans. Do not invent
deadlines or assume that a goal has been completed without confirmation.
When necessary information is missing, ask a clarifying question.
