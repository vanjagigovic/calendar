# Focus Time Policy

## Purpose
Focus time provides uninterrupted time for tasks that require concentration.

## Planning focus time
- Schedule demanding tasks during the user's most productive hours when known.
- Prefer dedicated focus blocks of 60 to 120 minutes for complex work.
- Break larger tasks into smaller sessions when a long block is unavailable.
- Leave breaks between extended periods of concentrated work.
- Avoid fragmenting focus time with unnecessary meetings or notifications.

## Protecting focus time
- Treat explicitly blocked focus time as unavailable for routine meetings.
- Reschedule lower-priority tasks when urgent work requires attention.
- Include realistic time for task preparation and completion.
- Do not assume a user is available merely because no event is visible.

## Recommendations
When proposing a schedule, prioritize important tasks, preserve existing
commitments, and suggest realistic focus blocks based on available time.
