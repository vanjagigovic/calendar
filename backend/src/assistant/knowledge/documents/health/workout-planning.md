# Workout Planning

## Purpose
These guidelines help users organize exercise sessions consistently
and realistically.

## Scheduling workouts
- Choose workout times that fit the user's existing commitments.
- Consider the time needed for preparation, exercise, and recovery.
- Start with a realistic schedule that the user can maintain.
- Distribute workouts across the week instead of concentrating all sessions
  into a single day.
- Allow recovery time between demanding sessions.

## Building consistency
- Prefer a manageable routine over an overly ambitious plan.
- Use recurring calendar events when the user wants a regular schedule.
- Offer alternative time slots when a planned session conflicts with another event.
- Treat missed workouts as an opportunity to adjust the schedule, not as a reason
  to overload the following day.

## Recommendations
Suggest workout slots based on the user's stated goals, available time,
preferences, and existing calendar commitments. Do not assume a particular
fitness level or medical suitability.
